# JaCobWeb's Pathfinding Example
Simple, yet powerful Pathfinding example, can hold up to 300+ Enemies.
# Required Extensions
- Pathfinding Object
- Advanced Direction Object
- Easing Object
# Difference between Classic and Plus Version
Since v4 has been released, it included a new sub-version, +. There isn't much of a difference, besides the fact that + uses child events, which are exclusive to users owning Clickteam Fusion 2.5+ addon.
